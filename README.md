# Gojo Saturo - Limitless Cursed Energy Calculator ♾️

An anime-themed web calculator inspired by **Satoru Gojo** from *Jujutsu Kaisen*. Packed with dynamic cursed energy visual effects, Limitless barrier physics, audio synthesizer effects, iconic Japanese voice lines, and full scientific math capabilities.

---

## ⚡ Features

### 1. **Gojo Satoru Visual Themes**
- **六眼 (Six Eyes)**: Electric azure and cyan infinity glow with pulsing cursed energy.
- **蒼 (Lapse: Blue)**: High-density cobalt aura with gravitational attraction.
- **赫 (Reversal: Red)**: Crimson radiant energy surge.
- **茈 (Hollow Purple)**: Collision of Blue and Red with cosmic purple distortion.

### 2. **Cinematic Jujutsu Techniques**
- **領域展開 (Domain Expansion: Unlimited Void)**:
  - Expands the celestial Six Eyes portal across the screen with Japanese kanji `無量空処` and cosmic particle bursts.
- **虚式「茈」 (Hollow Purple Blast)**:
  - Collides Blue and Red cursed energy spheres, releasing a screen-shaking purple explosion.
- **Limitless Barrier (Infinity Field)**:
  - Interactive background particles dynamically repel away from your mouse cursor, simulating Gojo's absolute defense!

### 3. **Mathematical Capabilities**
- **Standard Keypad**: Addition, subtraction, multiplication, division, modulo, negation, decimal precision.
- **Limitless (Scientific) Keypad**:
  - Trigonometric: `sin`, `cos`, `tan` with `DEG` / `RAD` toggle mode.
  - Logarithmic: `log` (base 10), `ln` (natural log).
  - Power & Roots: `√x`, `x²`, `x^y`, `x!`, `1/x`, `|x|`.
  - Constants: `π` (Pi), `e` (Euler's number).
  - Parentheses: `(` and `)` for complex algebraic expressions.
- **Memory Functions**: `MC`, `MR`, `M+`, `M-`.
- **Division by Zero / Infinity**: Triggers the Limitless Infinity Void easter egg with *"Nah, I'd win."*

### 4. **Audio Engine & Quotes**
- **Zero External Audio Files**: Built entirely on the HTML5 Web Audio API to synthesize responsive cursed energy chimes, resonant bass sweeps, and chord releases.
- **Voice Quotes**: Speaks iconic Gojo lines such as:
  - *"Don't worry, I'm the strongest."* (大丈夫、僕 最強だから)
  - *"Domain Expansion: Unlimited Void!"* (領域展開：無量空処)
  - *"Throughout heaven and earth, I alone am the honored one."* (天上天下唯我独尊)
  - *"Nah, I'd win."* (勝つさ)

### 5. **Cursed Scroll (Calculation History)**
- Slide-out log drawer preserving past calculations with timestamps.
- Click any past calculation to instantly recall the result back into the display.
- One-click *Exorcise History* to clear.

---

## 🚀 How to Run

1. **Option 1**: Double-click `open.bat` in the `d:\calculator` folder.
2. **Option 2**: Double-click `index.html` to open directly in any browser (Chrome, Edge, Firefox, Brave, Safari).
3. No installation, server, or dependencies required!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| `0` - `9` | Enter numbers |
| `+`, `-`, `*`, `/` | Arithmetic operators |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last digit |
| `Escape` | All Clear (AC) |
| `s`, `c`, `t` | `sin`, `cos`, `tan` |
| `p` | Insert `π` |
| `^` | Exponentiation ($x^y$) |
| `v` | Trigger Domain Expansion |
| `(`, `)` | Parentheses |
